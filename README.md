# Крипторобот — «Движение дня» на USDT-фьючерсах Bybit и Binance

Отдельный робот для криптовалют, сделанный по образцу робота Мосбиржи: те же настройки, но в USDT и по монетам.
Робот Мосбиржи он не использует и не трогает.

## Что торгует
- **Биржи:** Bybit и Binance, бессрочные USDT-фьючерсы (контракты), лонг и шорт, плечо по выбору (по умолчанию ×1).
- **Счета:** на каждой бирже демо-счёт и реальный счёт. Для каждого — свой ключ API (key + secret) с правами «чтение» и
  «торговля фьючерсами», **без права вывода**. Лучше разрешить ключу вход только с IP ваших серверов.
- **Валюта:** всё в USDT — счёт, сумма на сделку, обороты, результаты.
- **Чем торговать:** топ-20 / топ-50 / топ-100 монет по обороту за сутки или все USDT-фьючерсы.
- **День:** начинается в 03:00 МСК (00:00 UTC), движение монеты считается от цены в это время. Торговля круглосуточная,
  без выходных и календаря. Все времена в настройках — по Москве.
- **Индекс:** BTC — рост или падение биткоина от начала дня.

## Стратегия «Движение дня»
1. Монета ушла от начала дня на порог (по умолчанию 2,5%) → робот следит за ней.
2. Цена вернулась к середине между EMA10 и EMA20 (графики 5м / 15м / 1ч / 1д, можно несколько) → вход.
3. Стоп — за лоем дня (для шорта — за хаем), тейк — на хае дня (для шорта — на лое), иначе выход по времени.
4. Режимы (галочки): BTC вверх — лонг, BTC вниз — шорт, в обе стороны, только лонг, только шорт.
5. Один или несколько входов в день, перенос позиций (закрыть все / переносить все / только в плюсе, не дольше N дней),
   % счёта на сделку × плечо, ограничение позиции долей дневного оборота монеты, фильтры по обороту в день и объёму сегодня (в USDT).

## Программы
- **CryptoRobot.exe (Windows)** — вкладки «Автоторговля», «Рынки» (4 графика монеты), «Результаты»,
  «Проверка на истории», «Telegram», «Сервер и телефон», «Настройки».
- **CryptoRobot-android.apk** — пульт робота на сервере: позиции, кандидаты, графики, сделки, результаты, проверка на истории, настройки.
- **Сервер** — ставится из программы кнопкой «Установить / обновить сервер» на те же серверы, что у робота Мосбиржи, отдельно:
  папка `/opt/cryptorobot`, служба `cryptorobot`, порт **8444** (у робота Мосбиржи — `/opt/moexrobot`, 8443).
  Пара основной / резервный и «Обновить сервер без пароля» работают так же, как у робота Мосбиржи.
- **Telegram** — входы, выходы и переносы позиций.

Сборки Windows и Android делает GitHub Actions после каждого изменения: релиз **latest** этого репозитория.

## Проверка на истории
5-минутные свечи USDT-фьючерсов: архивы Binance `data.binance.vision` (по месяцам и дням), а чего там нет — через API выбранной биржи.
Затраты — 0,12% на сделку туда-обратно (комиссия тейкера и проскальзывание). Кэш свечей — папка `history_bt` рядом с программой.

## Ключи и безопасность
Ключи API хранятся только в `settings.json` рядом с программой и на вашем сервере (файл доступен только службе), в репозиторий
не попадают. Телефон и программа получают с сервера лишь отметку «ключ сохранён». Сертификаты в систему не ставятся.

## Связь с биржами
Кнопка «Проверить связь и ключи» (программа → «Настройки», телефон → «Настройки» → «Биржа и счёт») показывает, отвечают ли
Bybit и Binance с сервера и подходят ли ключи. Сервер делает эту проверку и при каждом запуске (журнал службы:
`journalctl -u cryptorobot -n 30`). Если биржа не отвечает с адреса сервера (HTTP 403 / 451 — доступ из страны закрыт),
нужен сервер в другой стране.
